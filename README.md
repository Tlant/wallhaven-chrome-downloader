# Wallhaven Download Manager

一个非官方的 Chrome 扩展，用于从 Wallhaven 页面挑选壁纸、解析原图地址，并建立可暂停的下载任务。仓库建议名称：`wallhaven-download-manager`。

本项目目前是 **1.1.0 测试版**。在大量下载前，建议先用两三张图片验证当前 Chrome 和 Wallhaven 登录状态。扩展不会在读取页面、勾选图片、解析 URL 或建立任务时自动开始下载。

## 功能

| 操作 | 结果 | Chrome 开启“每次询问保存位置”时 |
| --- | --- | --- |
| 逐张勾选、全选或取消当前网页图片 | 更新已选清单 | 不弹保存窗口 |
| 解析已选图片 | 显示真实原图 URL | 不弹保存窗口 |
| 复制 URL | 复制每行一条的 URL 文本 | 不弹保存窗口 |
| 导出 URL TXT | 保存一个文本文件 | 预计 1 次保存窗口 |
| 建立逐张下载任务 | 保存选中图片的任务快照 | 建任务时不弹；启动后每张预计 1 次 |
| 建立单个 ZIP 任务 | 逐张写入一个 ZIP | 建任务时不弹；最后预计 1 次 |

任务启动或继续前，确认框会显示该任务的图片总数、已完成张数、剩余张数和本次预计保存窗口数。下载任务只包含**建立任务当时**选中的图片，之后改变勾选不会修改既有任务。

## 安装

1. 若装过旧版“Wallhaven 批量下载器”，先在 `chrome://extensions` 中**禁用或移除旧版**。旧版与本项目是独立扩展，可能同时运行。
2. 下载本仓库代码并解压。打开 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择**包含 `manifest.json` 的仓库根文件夹**。不能直接选择 ZIP 文件。
4. 打开 Wallhaven 的搜索结果页、壁纸列表页或具体收藏夹，点击扩展图标。扩展会打开独立的管理页。

`https://wallhaven.cc/favorites` 及其分页可能只显示收藏夹列表。若管理页提示没有找到壁纸，请先进入具体收藏夹，再点击扩展图标或“读取当前网页图片”。

更新本地代码后，请到 `chrome://extensions` 点击此扩展的“重新加载”，再刷新 Wallhaven 页面和扩展管理页。

## 使用流程

### 1. 选择图片

管理页的“当前网页”区域显示本次从来源标签页找到的图片数量。可逐张勾选、全选当前列表或取消当前列表选择。“已选清单”会保留之前页面选过的图片，并逐一显示图片 ID；点击 ID 旁的 `×` 可单独移除。也可以清空整个已选清单。

“全选当前列表”只作用于管理页当前显示的图片，不会隐式选中其他页、整个收藏夹或整个网站。任务建立前请核对“已选清单”的数量和 ID。

### 2. 解析真实下载 URL

点击“解析已选图片的真实 URL”。默认模式为**网站登录状态**：扩展从原 Wallhaven 标签页读取图片详情页，浏览器自动附带该站点的 Cookie。扩展不会读取、复制或保存 Cookie 字符串。使用此模式时，请保持来源标签页打开，并确认你能在网站中手动打开目标图片。

可选“优先使用 API Key”。Wallhaven 的 API Key 在登录后的[账户设置页](https://wallhaven.cc/settings/account)获取。扩展调用官方 `/api/v1/w/{ID}` 并读取 `path` 字段。如果没有填写 Key，或 API 请求失败，扩展会尝试回退到网站登录状态。Key 只保存在本机 Chrome 扩展存储中，不会写入导出的 TXT。

解析后可以直接复制 URL，或导出 UTF-8 TXT；TXT 每行一张图片的原图地址。复制和导出只包含**当前已选**图片。

### 3. 建立并运行任务

选择“建立逐张下载任务”或“建立单个 ZIP 任务”。这一步只保存任务，不提交下载。到“任务详情”中核对张数，再点击继续按钮，并阅读二次确认框。

- **逐张保存：**使用 Chrome 下载接口，按任务顺序保存到默认下载目录下的 `Wallhaven` 文件夹。若 Chrome 开启“每次询问保存位置”，每张图片都可能弹出一次保存窗口。
- **单个 ZIP：**将图片逐张写入浏览器私有临时存储，最后向 Chrome 提交一个 ZIP 文件。ZIP 内部采用无压缩存储，以避免将全部原图同时放入内存。保持管理页打开，直到任务显示“已完成”。

任务详情显示已完成和剩余张数；逐张下载还显示当前文件已接收的字节数。可暂停后续下载，或取消任意任务。取消会尝试停止该任务当前正在下载的文件，已保存到磁盘的文件不会被删除。

## 中断与恢复

Chrome 或电脑关闭后，任务不会自动继续。重新打开管理页可查看已完成和剩余张数，手动确认后继续。

逐张下载依赖 Chrome 的下载接口。任务记录保留已完成图片，但正在下载的单张图片中断后可能需要从头下载；本扩展**不保证字节级续传**。暂停时已提交给 Chrome 的当前下载可能继续完成，扩展不会再提交下一张。

ZIP 写入浏览器的私有临时文件。中途关闭管理页后可以从**已完整写入 ZIP 的图片**继续；正在写入的那张会重新读取。最终 ZIP 最多支持 4 GB 或 65,535 张，超出时请分批建立任务。不要在 ZIP 任务完成前清除浏览器网站数据或扩展数据，否则临时文件及进度可能丢失。

## 权限与数据

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存已选清单、解析设置和任务记录 |
| `tabs`、`scripting` | 从你主动打开的 Wallhaven 标签页读取当前列表和壁纸详情 |
| `downloads` | 保存图片、ZIP 或 URL TXT，并读取下载进度 |
| `wallhaven.cc`、`w.wallhaven.cc` 站点访问权限 | 请求壁纸详情与原图 |

扩展不上传图片列表、Cookie 或 API Key 到开发者服务器。它直接与 Wallhaven 交互。API Key 保存在本机扩展存储；若不需要可在管理页的设置里清空。

## 常见问题

**解析返回 HTTP 401。** API 对部分受限图片要求有效的 API Key。可关闭“优先使用 API Key”并使用已登录的网站标签页解析，或在账户设置中获取 Key。若网站登录状态也失败，请确认来源标签页仍打开、已登录，且能手动访问该图片。

**管理页没有图片。** 当前网页可能是收藏夹目录，而不是具体收藏夹；也可能图片尚未加载。进入有缩略图的页面后重新读取。

**为什么会弹出多个保存窗口？** 逐张任务会为每张图片调用一次 Chrome 下载接口。确认框会按剩余图片数提前提示。若希望只出现一次保存窗口，选择单个 ZIP 任务。

**关闭 Chrome 后会自动下载吗？** 不会。任务保持暂停，必须在管理页手动继续并再次确认。

**ZIP 打包失败后需要从头开始吗？** 已经完整写入 ZIP 的图片可保留；正在写入的图片会重试。浏览器临时数据被清理或 ZIP 超过格式上限时，需要重新建立或拆分任务。

## 项目结构

```text
manifest.json       Chrome Manifest V3 声明与权限
background.js       逐张下载队列、状态、暂停与取消
manager.html        管理页结构
manager.css         管理页样式
manager.js          图片选择、URL 解析、任务交互
zip.js              流式 ZIP 写入与中断后续写
icons/              用户提供的 ICO 原件及 Chrome 图标尺寸
```

项目不依赖运行时 CDN、构建工具或第三方 JavaScript 包。修改代码后可在 `chrome://extensions` 重新加载扩展。建议先执行 JavaScript 语法检查，并在独立 Chrome 测试配置中验证实际下载行为。当前已经完成模拟任务测试，以及 ZIP 中断后续写并通过 Python `zipfile` 读取的检查；尚未在所有 Chrome 下载设置和 Wallhaven 页面类型中做端到端验证。

在仓库根目录可运行：

```powershell
node --check background.js
node --check manager.js
node --check zip.js
node tests/task-safety.mjs
node tests/zip-resume.mjs
```

这是非官方工具，与 Wallhaven 无隶属关系。壁纸仍归各自原作者所有。`icons/source-favicon.ico` 是用户提供的 Wallhaven 图标；在将仓库设为公开前，请自行确认该图标的再分发许可。Chrome 扩展图标采用该原图居中生成的 PNG；Chrome 官方建议为工具栏和扩展管理页提供多个尺寸的图标，见[图标文档](https://developer.chrome.com/docs/extensions/reference/manifest/icons)。
