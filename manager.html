下载设置

仅影响之后新建的任务

文件保存在 Chrome 默认下载目录内。扩展只能指定其中的相对路径；如需更换下载根目录，请到 chrome://settings/downloads 修改。

保存位置确认框也可能被超时检测中断；使用“每次询问保存位置”时，建议保持超时为 0。短于 30 秒的间隔在 Chrome 休眠后台扩展时可能延长。

解析方式

不勾选时，使用当前 Wallhaven 标签页的登录状态读取图片详情，浏览器会自动附带该网站的 Cookie。勾选后若 Key 未填写或失效，会自动回退到网站登录状态。

填写 API Key（可选）

登录 Wallhaven 后，在账户设置获取 API Key。Key 只保存在本机扩展存储，不会写入 URL 文本。
